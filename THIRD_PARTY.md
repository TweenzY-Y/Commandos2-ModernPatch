# Third-party components

## cnc-ddraw

Release packages of Commandos2-ModernPatch include an unmodified build of
[cnc-ddraw](https://github.com/FunkyFr3sh/cnc-ddraw) (version 7.1.0.0) in
`Commandos2-ModernPatch\cnc-ddraw\`. It is used as the DirectDraw backend when
`CncDDraw=1` (borderless full screen, scaling, no display mode switches).
